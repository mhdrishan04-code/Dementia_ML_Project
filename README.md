# Classification and Analysis of Dementia Using Machine Learning

A simple college-level machine learning project for classifying dementia from patient health data.

## Dataset
- 1,000 patient records
- 24 columns
- Target: `Dementia`

## Algorithms
- Logistic Regression
- Decision Tree
- Random Forest

## Evaluation
- Accuracy
- Precision
- Recall
- F1-score
- Confusion Matrix
- Feature Importance

## Project Structure
```text
Dementia_ML_Project/
├── data/
│   └── dementia_patients_health_data.csv
├── models/
├── outputs/
│   └── graphs/
├── dementia_prediction.py
├── requirements.txt
├── README.md
└── app.py
```

## Run
```bash
pip install -r requirements.txt
python dementia_prediction.py
```

This project is for educational purposes and is not a clinical diagnostic system.
